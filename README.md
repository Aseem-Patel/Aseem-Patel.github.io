# Papers

PDFs of Aseem Patel's papers, served by GitHub Pages and linked from
https://sites.google.com/view/aseempatel/research

| Paper | Link |
|-------|------|
| Labour Market Power, Automation and Welfare | https://aseem-patel.github.io/papers/LMPAW.pdf |

## Update a paper

Copy the new PDF over the old one with the same filename, then commit and push.
The link does not change.

## Add a paper

Put the PDF in `papers/` under a short fixed name (no dates), add a row above,
commit and push, then link `https://aseem-patel.github.io/papers/<name>.pdf`
from the Research page.
